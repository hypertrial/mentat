# Local trial coordinator (v1)

A trusted local caller starts or resumes a bounded trial for one clean repository, exact full base commit and request ID. The caller supplies any repair allowlist; an empty allowlist grants no application edits. State and integration rendezvous remain outside the application checkout. Repeating the same request returns or resumes the same session; mismatched inputs fail closed and completed work is not replayed. A completed or blocked session may process newly queued typed feedback before its original deadline. Local-only authority is persisted and checked at the publication boundary before any remote effect. Trials run for at most 3600 seconds with at most three attempts per job; repository configuration and feedback cannot expand authority. Source-only repositories do not need committed Mentat configuration or a remote. Generated material and approved requirements remain distinguishable, and inventory is available through bounded loopback observation with path, status and reason.

Regression surfaces include existing run/resume, project verification, publication and typed feedback. Validation covers clean/exact checkout, idempotence and mismatch, terminal resume, local-only publication, source-only bootstrap and observation bounds. No live model or publication is used in tests. Required full and Linux-worker gates are recorded separately when available.

## Implementation evidence and handoff

The Coordinator local runtime selects at most one session from each request state under its exclusive lock. It pins the exact request and original deadline, uses the committed configuration or trusted source-only defaults, rejects unpinned shell checks, and prevents publication before reaching any remote gateway. Repairs require exact caller-authorized paths; absent paths stop repair before invoking an agent. A completed or blocked session can process newly queued typed feedback before its original deadline. Live leases prevent resume before expiry; at expiry an interrupted session is marked blocked with an inconclusive finding while preserving unconfirmed worker state. The inventory resource marks a path mapped only when a current reviewed requirement has a bound digest and cites that path at the pinned base. Older review events without requirement digests stay unmapped.
