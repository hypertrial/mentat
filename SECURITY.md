# Security policy

Use [GitHub private vulnerability reporting](https://github.com/hypertrial/mentat/security/advisories/new)
to report a vulnerability in Mentat. Include the affected version, impact, and
minimal reproduction. Review any attached logs or evidence for credentials,
private source, and local paths before sharing.

The public prerelease is the supported release line. See the
[runner documentation](docs/contracts.md#runners) for the permissions required
by Docker, host checks, and Lean.
